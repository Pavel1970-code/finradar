# Детерминированный налоговый профиль компании

Версия каталога вопросов: 1.  
Дата нормативной проверки: 25 июля 2026 года.

Источники:

- [Закон Грузии «О предпринимателях»](https://matsne.gov.ge/ka/document/view/5230186)
- [Налоговый кодекс Грузии, публикация 245](https://matsne.gov.ge/ka/document/download/1043717/245/ge/pdf)

## Что реализовано

Локальный каталог содержит 24 заранее определённых вопроса. Генеративный ИИ не
участвует в их создании, выборе или обработке ответов.

Каталог охватывает:

- юридическую форму;
- грузинское или иностранное предприятие;
- постоянное учреждение иностранного предприятия;
- основной вид деятельности и муниципалитет;
- режимы индивидуального предпринимателя;
- специальные статусы предприятия;
- регулируемые виды деятельности;
- регистрацию по НДС;
- наличие работников;
- импорт и доступность товарных кодов;
- подакцизные операции и доступность классификационных данных;
- имущество и землю;
- дивиденды, проценты и выплаты нерезидентам;
- налоговые льготы.

## Ветвление

Вопрос появляется только при выполнении закодированного условия.

Примеры:

- режим микробизнеса/малого бизнеса спрашивается только у индивидуального
  предпринимателя;
- специальные статусы предприятия спрашиваются только у юридических лиц;
- дата регистрации по НДС спрашивается только после ответа `Да`;
- наличие товарных кодов спрашивается только при наличии импорта;
- кадастровые данные спрашиваются только при наличии земли.

Все условия используют стабильные значения вариантов ответа. Свободный текст не
интерпретируется как налоговое решение.

## Состояния профиля

- `complete` — на все видимые обязательные вопросы есть определённые ответы;
- `incomplete` — отсутствует ответ или выбрано `Не знаю`;
- `conflict` — ответы юридически или логически противоречат друг другу.

Отсутствие подтверждающего документа не подменяет ответ, но создаёт отдельное
предупреждение.

## Локальное хранение

Профиль сохраняется в таблице `tax_profile_versions`:

- только добавление новых версий;
- canonical JSON;
- SHA-256;
- запрет `UPDATE` и `DELETE`;
- период действия каждого ответа;
- источник и статус проверки.

Миграция: `0008_tax_profile`.

## Связь с налоговыми ставками

Профиль преобразуется в набор машинных фактов. Например:

- юридическая форма и резидентство → `entity_tax_status`;
- выбранный режим → `micro_business_status`, `small_business_status` или
  `fixed_taxpayer_status`;
- ответ о льготах → `applicable_reliefs`.

Эти факты объединяются с транзакционными фактами из бухгалтерии и нормативными
классификаторами. После этого система может перечислить конкретные недостающие
данные для выбранного налогового правила.

## Что ещё не реализовано

- экран первоначальной настройки;
- автозаполнение вопросов из реальной 1С;
- получение подтверждённых статусов из публичного реестра;
- общий resolver применимости всех налоговых правил;
- автоматическое применение профиля в desktop forecast;
- редактирование профиля пользователем через UI.

Следующий UI не должен содержать собственную налоговую логику: он будет
отображать вопросы из этого каталога и сохранять ответы через локальный сервис.
